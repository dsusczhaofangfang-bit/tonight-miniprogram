## 1. 第一原则：从主题出发，拒绝模板

每一个视觉决策都要能回答：**为什么是柠舍唔同，而不是任何一家酒吧？**

以下是被点名的「AI 生成感」默认特征。出现时必须能论证其必要性，否则改掉：

1. 奶油色背景 + 高对比衬线标题 + 陶土色点缀；
2. 近黑背景 + 单一荧光色（酸性绿 / 朱红）点缀；
3. 报纸式密集分栏 + 零圆角 + 细线规则；
4. SaaS 卡片套件：内容切成同质圆角卡片、所有层级同一圆角、同款灰阴影、渐变装饰；
5. 通用装饰语法：全大写小标签、标题上方的眉标、中点分隔的元信息（A · B · C）、每个链接后加箭头、用 `#0B0B0B` 冒充纯黑。

**本项目的处理**：暗色 + 金色 + 衬线是 brief 指定的方向，照做，不算违规；差异化必须来自排版、结构、动效编排、文案与自有记号（见第 7 节），而不是换一套配色。

## 2. 字体

- 家族：中文系统衬线 `"Songti SC", "Noto Serif SC", "STSong", serif`；拉丁 `Georgia`。不加载网络字体。
- 字阶（rpx）：88 品牌 / 56 页面题 / 40 区块题 / 32 商品名 / 28 正文 / 22 辅助 / 18 标签。
- 行高：标题 1.2，正文 1.7；标题字距 8–16rpx；正文不超过 1rpx。
- 行宽：正文每行不超过约 24 个汉字（折算 < 80 字符），左右留白不小于 32rpx。
- 禁止：标题里单独一个词变色 / 斜体 / 加粗强调；标题上方的眉标；把全大写用于小标签。
- 例外：品牌英文 `COCKTAIL & WHISKEY BAR` 作为锁定组合可全大写；价格数字用 Georgia。

## 3. 结构与布局

- 结构元素必须编码信息。分隔线、边框、标签、编号都要回答「它告诉用户什么」。
- 编号只用于真实序列（如订单状态时间线），不用于商品列表。
- 默认左对齐；仅欢迎页允许仪式性居中。
- 卡片限制：圆角 ≤ 8rpx；默认无投影；优先用 1rpx 香槟金细线分隔（透明度约 25%）。唯一例外：详情页底部内容面板可有一层阴影。
- 每屏只能有一个视觉主角；主角之外全部降噪。

## 4. 动效

- 全站唯一重动效：欢迎页玫瑰花瓣与文字入场。其余页面不做滚动入场、卡片悬浮、渐变流动。
- 交互反馈允许 150–250ms 的透明度/位移变化，且必须解释状态变化。
- 实现约束：只用 `transform` / `opacity`；动画期间不高频 `setData`；离开页面立即停止。

## 5. 文案

- 用户视角、主动语态；按钮名即结果（「进入酒馆」「开始点单」）。
- 同一动作全流程同名，按钮、提示、结果页用词一致。
- 错误说明「发生了什么 + 怎么改」，不道歉、不模糊。
- 空状态是行动邀请，不是情绪表达。
- 不写营销腔，不用 emoji，标点克制；示例数据必须标注「示例」。

## 6. 每阶段视觉工作流程（强制）

1. **写设计计划**：≤6 个命名色值、字体角色、布局概念 + ASCII 线框、设计原则。
2. **对照 brief 自查**：逐条问「这个选择换到任何同类项目还成立吗？」成立则视为默认值，改。
3. **再写代码**：按修正后的计划实现，注意 WXSS 选择器特异性，避免样式互相抵消。
4. **完成后自评**：删掉一个装饰；确认视觉主角唯一；真机检查；对照第 8 节清单。

## 7. 本项目已确定的视觉决策

| 决策 | 内容 |
| --- | --- |
| 唯一大胆处 | 欢迎页玫瑰花瓣逐片坠落 + 文字依次浮现 |
| Logo | 暂不使用 Logo、印章或水印；品牌以「柠舍唔同 + COCKTAIL & WHISKEY BAR」文字标识呈现，正式 Logo 到位后单独评估 |
| 酒单结构 | 编辑式列表 + 左侧竖排分类栏，不做双列卡片货架 |
| 门店信息 | 门牌式细线排版，不做通用信息卡 |
| 色板 / 字体 | 沿用需求文档第 7 章，不另起一套 |

## 8. 提交前评审清单

- [ ] 未出现第 1 节的模板特征（或已逐条论证）
- [ ] 标题无单词强调；无眉标；无全大写小标签（品牌锁定除外）
- [ ] 编号仅用于真实序列
- [ ] 卡片圆角 ≤ 8rpx、无投影；全站仅详情面板一处阴影
- [ ] 全站仅欢迎页有重动效
- [ ] 按钮文案即动作结果，全流程用词一致
- [ ] 示例数据均有「示例」标注
- [ ] iOS、Android 各一台真机通过

## 9. 维护

- 新增页面或改版前先读本文件；设计计划写入对应阶段的文档（如 `05-M1设计计划.md`）。
- 如需要偏离某条准则，在 PR / 交付说明中写明原因，经确认后执行。
