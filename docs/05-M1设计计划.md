## 1. 从主题出发

- **主题**：私人鸡尾酒吧，深夜、玫瑰、威士忌、暖光；粤语店名「柠舍唔同」。
- **观众**：20–35 岁到店客人（约会、小聚、一个人来喝一杯）；同时要经得起老板当面演示。
- **首要任务**：3 秒内让人觉得「这不是普通酒吧」，并愿意继续点单。
- **唯一大胆处**：玫瑰花瓣逐片坠落 + 文字依次浮现。除此之外全部克制，不加第二个动效。

## 2. Token 系统

### 2.1 色（6 个命名色）

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨黑 | `#0B0A09` | 页面底色 |
| 胡桃木 | `#241610` | 面板、凹陷区、图片占位底 |
| 酒红 | `#5A1A24` | 主按钮底 |
| 玫瑰红 | `#A32B41` | 强调、花瓣主色 |
| 琥珀 | `#D9A45B` | 价格、高亮、激活态 |
| 米白 | `#F4ECDF` | 主文字 |

香槟金 `#C9A86E` 作为琥珀的衍生色，仅用于 1rpx 分隔线与次级文字，不单独成块。

### 2.2 字体

- 中文：系统衬线栈；拉丁：Georgia；不加载网络字体。
- 字阶（rpx）：88 品牌 / 56 页面题 / 40 区块题 / 32 商品名 / 28 正文 / 22 辅助 / 18 标签。
- 标题字距 8–16rpx，正文 0–1rpx；行高 1.2（标题）/ 1.7（正文）。
- 价格用 Georgia；¥ 符号比数字小一号。

### 2.3 布局

- 外边距 32rpx；间距基准 8rpx；分隔线 1rpx `rgba(201,168,110,.25)`。
- 圆角 ≤ 8rpx；全站无投影，唯一例外是详情页底部内容面板。
- 左对齐为主；欢迎页居中；每屏一个主角。

| 项 | 方案 |
| --- | --- |
| 数量 | 主角 12 片（从玫瑰散开）+ 环境 12 片（循环）；低端机 8 + 6 |
| 尺寸 | 20–140rpx（近景 96–140rpx） |
| 时长 | 主角 8s 一次走完出屏；环境 6–11s 循环 |
| 延迟 | 主角统一 1.0s 起；环境 2.0s 起，错峰 0–2.6s |
| 轨迹 | 主角：簇内 → 外扩 90–200rpx → 120vh；环境：纵向下落 + 横向漂移 ±80rpx + 旋转 180–540° |
| 透明度 | 0.30–0.95；远景 0.30–0.42，近景 0.88–0.95 |
| 层级 | 环境 1 < 主角 2 < 玫瑰 3 < 文字 6 |
| 实现 | `components/petal-field`（12 条 hero keyframes + 4 条环境轨迹 + 2 条近景轨迹）+ `components/rose-stage`；纯 CSS，运行期零 setData、零定时器 |
| 降级 | `quality=lite`：8 + 6、去预模糊、去轮廓光；`PETAL_COUNT ≤ 5` 同样触发 |
| 资源 | 真实玫瑰与花瓣素材 → `scripts/prepare_rose_assets.py` 生成 `-lit` / `-soft` 派生版 |

## 6. 对照 brief 的模板化自查（skill 第二步）

| 可能的默认值 | 判定 | 处理 |
| --- | --- | --- |
| 暗底 + 金色 + 衬线 = 常见酒吧模板 | brief 已指定，保留 | 用竖排分类、编辑式列表、单一动效与留白建立差异 |
| 双列商品卡片 = 电商模板 | 默认值 | 改为编辑式列表 + 左侧竖栏 |
| 通用信息卡 + 同款圆角阴影 | 默认值 | 改为门牌式细线排版，无阴影 |
| 眉标 / 全大写小标签 / 中点元信息 / 箭头 | 默认值 | 全部不用；品牌英文锁定组合除外 |
| 每段淡入、每卡悬浮 | 默认值 | 仅欢迎页动效 |
| 用 #0B0B0B 冒充黑 | 默认值 | 使用 #0B0A09（带一点暖调） |

结论：方案按上表修正后执行，不采用任何未论证的模板语法。
