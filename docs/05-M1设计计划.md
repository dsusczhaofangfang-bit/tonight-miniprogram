## 1. 从主题出发

- **主题**：私人鸡尾酒吧，深夜、玫瑰、威士忌、暖光；粤语店名「柠舍唔同」。
- **观众**：20–35 岁到店客人（约会、小聚、一个人来喝一杯）；同时要经得起老板当面演示。
- **首要任务**：3 秒内让人觉得「这不是普通酒吧」，并愿意继续点单。
- **唯一大胆处**：欢迎页纯文字排版 + 0.10–0.85s 文字依次淡入（玫瑰花瓣方案已于 2026-11-02 废弃）。除此之外全部克制，不加第二个动效。

## 2. Token 系统

### 2.1 色（6 个命名色）

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨黑 | `#0B0A09` | 页面底色 |
| 胡桃木 | `#241610` | 面板、凹陷区、图片占位底 |
| 酒红 | `#5A1A24` | 主按钮底 |
| 玫瑰红 | `#A32B41` | 强调、分类激活竖条 |
| 琥珀 | `#D9A45B` | 价格、高亮、激活态 |
| 米白 | `#F4ECDF` | 主文字 |

香槟金 `#C9A86E` 作为琥珀的衍生色，仅用于 1rpx 分隔线与次级文字，不单独成块。

### 2.2 字体

- 中文：系统衬线栈；拉丁：Georgia；不加载网络字体。
- 字阶（rpx）：88 品牌 / 56 页面题 / 40 区块题 / 32 商品名 / 28 正文 / 22 辅助 / 18 标签。
- 标题字距 8–16rpx，正文 0–1rpx；行高 1.2（标题）/ 1.7（正文）。
- 价格用 Georgia；¥ 符号比数字小一号。

### 2.3 布局

- 外边距 32rpx；间距基准 8rpx；分隔线 1rpx `rgba(201,168,110,.25)`。
- 圆角 ≤ 8rpx；全站无投影，唯一例外是详情页底部内容面板。
- 左对齐为主；欢迎页居中；每屏一个主角。

### 3.3 酒单

> 2026-11-02 第三阶段已实现。相对本计划的增补：常驻搜索栏与条目内「加入」入口（用户第三阶段要求）；其余按线框执行。

```text
┌────────────────────────────────┐
│ 搜索酒名                        │  ← 常驻搜索，底部细线收口
├─────────┬──────────────────────┤
│ 全部    │ 全部          共 24 款 │
│ ▌传统饮品│ ─────────────────── │
│  特调饮品│ ┌───┐示例·传统饮品 01 │
│  无酒精  │ │酒 │Demo Classics 01 │
│  小吃    │ │标 │示例数据：风味…   │
│         │ └───┘¥58.00  详情  加入│
└─────────┴──────────────────────┘
```

- 左侧竖排分类栏（160rpx），首项为「全部」，激活项用 4rpx 玫瑰红竖条 + 米白文字；切换后列表与计数同步。
- 右侧编辑式列表：左侧酒标式占位块（132×168rpx）或真实图片，右侧名称、英文名、两行简介，底部价格与「详情 / 加入」；条目间只用细线分隔。
- 不做双列卡片货架；无真实图片用酒标占位块，`image` 有值自动换成真实图片，加载失败自动退回占位块。
- 搜索按中文名 / 英文名过滤，逻辑放在 `services/products.listProducts({ category, keyword })`，页面不重复过滤。
- 条目点击进详情；「加入」按 1 件加购并同步购物车角标（原 M1 计划不加购，第三阶段按用户要求增加）。

## 6. 对照 brief 的模板化自查（skill 第二步）

| 可能的默认值 | 判定 | 处理 |
| --- | --- | --- |
| 暗底 + 金色 + 衬线 = 常见酒吧模板 | brief 已指定，保留 | 用竖排分类、编辑式列表、单一动效与留白建立差异 |
| 双列商品卡片 = 电商模板 | 默认值 | 改为编辑式列表 + 左侧竖栏 |
| 通用信息卡 + 同款圆角阴影 | 默认值 | 改为门牌式细线排版，无阴影 |
| 眉标 / 全大写小标签 / 中点元信息 / 箭头 | 默认值 | 全部不用；品牌英文锁定组合除外 |
| 每段淡入、每卡悬浮 | 默认值 | 仅欢迎页动效 |
| 用 #0B0B0B 冒充黑 | 默认值 | 使用 #0B0A09（带一点暖调） |

结论：方案按上表修正后执行，不采用任何未论证的模板语法。
