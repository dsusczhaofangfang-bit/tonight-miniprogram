## 1. 素材实测（决定视觉上限的数据）

| 素材 | 画布 | 透明底 | 主体亮度 mean / p95 | 边缘相对本体 |
| --- | --- | --- | --- | --- |
| `rose-main.png`（源） | 754×673 | 是，留白 3.1–3.9% | 23.1 / 61.2 | +33% ~ +91%（自带轮廓光） |
| `q rose-main-lit.png`（分级） | 754×673 | 是 | **61.8 / 146.4** | +25% ~ +57% |
| `petal-01..06.png`（源） | 242–385 | 是 | 21.5–36.5 / 35.5–94.9 | +16% ~ +124% |
| `petal-0X-lit.png`（分级） | 208×256 ~ 256×169 | 是 | 65–74 / **113–132** | +4% ~ +88% |

结论与处理：

1. **原玫瑰太暗**（平均亮度 9%，与 `#0B0A09` 明度差仅 13–51 级），分级后 mean 61.8、p95 146.4，高光裁剪 0.29%，暗部占比从 21.98% 降到 0.88%。暗部集中在花心（半径 0.10–0.25 处近黑像素占 54%），属真实阴影，不是抠图残留。
2. **光源在上方**：上象限 mean 29.9/27.7、下象限 17.6/17.9。因此页面光环必须偏上（`top≈24vh`），不能做成居中均匀发光。
3. **花瓣亮度差 3 倍**，已按 p95=132±3 统一，同 `opacity` 下存在感一致。
4. **`petal-02` / `petal-06` 自带 +95%~124% 亮边**，分级后降到 +71%~+88%。这是素材本身的边缘受光，不是分级引入；若真机截图里读成"描边"，再加一轮边缘压暗（脚本已留 `bleed_edge` 入口）。

## 2. 分级参数（可复现）

```bash
python scripts/prepare_rose_assets.py
```

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 曲线 | `y = x(1+a)/(1+ax)` + 高光软肩 | 抬中暗调、保纯黑点、压高光 |
| 玫瑰 | `a=4.2`，`sat=1.05`，目标 p95=150 | 实测落到 146.4 |
| 花瓣 | `a=4.6`，`sat=1.04`，目标 p95=132 | 实测 113–134 |
| 边缘 | `bleed_edge` 全图扩散 | 半透明像素取最近本体色，防暗底亮边 |
| 缩放 | **预乘 alpha** 的 LANCZOS | 直接缩放会产生暗边 |
| 模糊 | 预乘 alpha，radius = 长边×2.8% | 近景 3 片专用 |
| 输出 | 只写 `-lit` / `-soft` | 源文件零改动，可反复重跑 |

## 4. 画布与层级

```text
z=0  背景：#0B0A09 + 顶部玫瑰色径向光晕（top -18vh，宽 150vw）
z=1  环境花瓣：12 片（远 5 / 中 4 / 近 3），无限循环
z=2  hero 花瓣：12 片，从玫瑰内部散开
z=3  玫瑰：754×673，宽 66vw，顶部 30vh（视觉中心 30vh + 221rpx）
z=6  品牌 / 欢迎语 / 按钮
z=7  跳过
```

玫瑰盖住 hero 花瓣，是"解体"连贯性的关键：玫瑰淡出时花瓣从它体内穿出，不需要玫瑰整体缩放消失。

## 7. 环境层与景深

| 层 | 数量 | 尺寸 | opacity | 时长 | 素材 |
| --- | --- | --- | --- | --- | --- |
| 远 | 5 | 20–30rpx | .30–.42 | 9–11s | `-lit` |
| 中 | 4 | 34–50rpx | .55–.75 | 7–9s | `-lit` |
| 近 | 3 | 96–140rpx | .88–.95 | 5.5–7s | `-soft` |

- `left` 分布在 0–96%，但避开 18–26%、48–58%、76–84% 三段形成空档，避免"雪花式均匀"。
- **安全区** `x∈[20,80] ∧ y∈[22,78]` 只允许远/中景；近景仅限 `x<18 ∨ x>82 ∨ y<10`。
- 以上两条在实现时写成数据断言，运行前脚本校验，不靠肉眼。
