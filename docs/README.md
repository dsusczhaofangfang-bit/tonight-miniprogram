## 维护约定

1. 新增文档按顺序编号，不覆盖旧文档；过时内容在标题下标注「已废弃」与替代文档。
2. 交付说明写完即在文末补「验收记录」（日期 + 用户反馈 + 对应 commit）。
3. 文档内的相对链接指向同目录文件，不写绝对路径。
