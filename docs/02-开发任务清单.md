2. 扫 `?table=t_a1` 进入，结算页自动带出 A1；手动改 B2 生效；不选桌提交被拦截。
3. 提交后进入模拟支付页，页面明确显示「模拟支付，不会产生真实扣款」；确认后订单详情状态为「待接单」。

**测试方法**

1. 未登录直接访问后台路由 → 跳转登录页；错误口令提示；正确口令进入工作台。
2. 新建商品 → 酒单可见；下架 → 酒单不可见；修改价格 → 详情与购物车同步。
3. 新建分类 → 酒单出现；分类下有商品时删除被阻止。
4. 新订单出现在「待接单」→ 接单 → 制作中 → 完成；每一步后台与顾客端状态一致；重复点击不产生重复流转。
5. 历史订单按日期筛选结果正确；今日订单数与营业数据口径一致。
