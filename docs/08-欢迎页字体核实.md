## 5. 加载方式与回退

```css
@font-face { font-family: "HakkouMincho";     src: url("data:font/ttf;base64,...") format("truetype"); }
@font-face { font-family: "HakkouFallbackSC"; src: url("data:font/ttf;base64,...") format("truetype"); }
```

页面使用：

```css
font-family: "HakkouMincho", "HakkouFallbackSC", "Songti SC", "STSong", serif;
```

| 环节 | 行为 |
| --- | --- |
| 正常 | 37 字用八公明朝，6 字用备用宋体 |
| 内嵌字体解析失败 | 整页退到 `Songti SC`/`STSong`/系统衬线，**不会出现豆腐块** |
| 为什么不放包内路径 | 小程序 `@font-face` 只认网络地址 / base64，包内路径在真机不生效 |
| 为什么不用 `wx.loadFontFace` | 它对本地路径的支持在不同基础库和真机上不一致，base64 内嵌没有加载时序问题 |
