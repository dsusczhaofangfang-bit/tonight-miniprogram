## 怎么截

1. 微信开发者工具中选择 **iPhone 14 Pro** 模拟器（逻辑宽度统一，四张图并排不会高低不齐）。
2. 用工具栏的「截图」按钮；或用 `Win + Shift + S` 直接框选模拟器内容并保存。
3. 保存为 PNG，宽度保持 1170px 左右即可；单张控制在 500 KB 以内。
4. 去掉鼠标指针、调试面板和开发者工具浮层；不要露出本机路径。
5. 真机截图也可以，但请六张统一机型，否则并排会很乱。
