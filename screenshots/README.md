## 重新截图时

1. 微信开发者工具中选择 **iPhone 14 Pro** 模拟器，保持 8 张统一机型。
2. 用工具栏「截图」按钮，或用 `Win + Shift + S` 框选模拟器内容。
3. 保存为 PNG，宽度 570px 左右即可；单张控制在 300 KB 以内（当前共约 810 KB）。
4. 去掉鼠标指针、调试面板和本机路径；不要露出真实账号或真实订单。

## 发布前检查

- 截图里不能出现真实个人信息、微信号、手机号。
- 商品统一使用「示例·」前缀的演示数据，与 README 的免责声明一致。
- 欢迎页字体混排（过、样、欢、进、馆）在截图里应看不出明显差异，否则先看 [docs/08-欢迎页字体核实.md](../docs/08-欢迎页字体核实.md)。
